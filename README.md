# Catch-A-Rock
The first game i successfully published to a web portal (Crazygames).

## Description:
Catch-A-Rock is a quirky blend of tower defense and roguelike action where you play as a heroic cat protecting your crystal-trapped brother. Hurl rocks at waves of enemies charging from both sides, unlock powerful new abilities, and choose upgrades between battles to grow stronger with each level.
